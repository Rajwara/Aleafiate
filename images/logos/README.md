# Logos

Upload the Aleafiate logo files from the designer here.

- **Darker logo**: for light backgrounds (the header on most pages, light footers). Name it `aleafiate-logo-dark` plus its extension (e.g. `.svg` or `.png`).
- **Lighter logo**: for dark backgrounds (the navy footer, over the banner photo). Name it `aleafiate-logo-light` plus its extension.

SVG is best because it stays sharp at any size. Otherwise, use a PNG with a transparent background, at least 600 px wide.

Upload any other versions too (icon only, stacked, etc.), then tell Claude which is which.

The site currently uses `images/brand/aleafiate-logo.png` (dark) and `images/brand/aleafiate-logo-white.png` (light). Once the new files are here, Claude will switch every page over.
