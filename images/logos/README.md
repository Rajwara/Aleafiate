# Logos and favicons

| File | Used for |
|---|---|
| `aleafiate-logo-dark.svg` | Navy logo (designer's SVG) for light backgrounds: the header on every page and light footers |
| `aleafiate-logo-light.svg` | White logo (designer's SVG) for dark backgrounds: the navy footer |
| `../../favicon.svg`, `../../favicon.ico` | Browser tab icon: the flame from the logo on navy |

The logo SVGs are the designer's files with the canvas trimmed to the artwork, so the logo lines up with the page. To replace one, upload the new file with the same name.
