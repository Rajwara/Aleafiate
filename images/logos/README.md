# Logos and favicons

Upload the designer's SVG logo files here, then tell Claude which is the dark logo (for light backgrounds), the light logo (for dark backgrounds) and the icon/favicon, if there is one.

The pages point at `aleafiate-logo-dark.svg` and `aleafiate-logo-light.svg` in this folder, so files uploaded with those names appear straight away.

The browser-tab icon is `favicon.ico` in the site root.
