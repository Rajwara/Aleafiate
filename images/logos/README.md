# Logos and favicons

| File | Used for |
|---|---|
| `aleafiate-logo-dark.svg` | Navy logo for light backgrounds: the header on every page and light footers |
| `aleafiate-logo-light.svg` | White logo for dark backgrounds: the navy footer |
| `favicon-32.png`, `../../favicon.ico` | Browser tab icon (the flame mark on navy) |
| `apple-touch-icon.png` | Icon when someone saves the site to an iPhone/iPad home screen |
| `favicon-192.png`, `favicon-512.png` | Android home screen / app icon (see `site.webmanifest`) |

The two logos are vector (SVG) versions traced from the designer's files, so they stay sharp at every size and on every screen. If the designer can supply official SVG files, upload them here and Claude will swap them in.
