# Logos and favicons

| File | Used for |
|---|---|
| `aleafiate-logo-dark.webp` | Navy logo for light backgrounds: the header on every page and light footers |
| `aleafiate-logo-light.webp` | White logo for dark backgrounds: the navy footer |
| `favicon-32.png`, `../../favicon.ico` | Browser tab icon (the flame mark on navy) |
| `apple-touch-icon.png` | Icon when someone saves the site to an iPhone/iPad home screen |
| `favicon-192.png`, `favicon-512.png` | Android home screen / app icon (see `site.webmanifest`) |

The two logos are the designer's files, trimmed of their empty border so they line up with the page. To replace one, upload the new file with the same name.
